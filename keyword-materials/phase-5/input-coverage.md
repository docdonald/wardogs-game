- WARDOGS 玩法、访问和经济事实优先使用 Steam、Team17、BULKHEAD 官方视频和官方社区页面。
- Battlefield、Squad、Arma 的对比字段只从各自官方页面或 Steam 官方商店页提取；媒体文章仅作搜索意图和玩家感知背景。
- Steam Community 普通讨论帖不升级为官方事实；只用于发现问题、寻找待核验主题和观察社区需求。
- Alpha Key 只记录历史发放规则和合法访问路径，不保存或生成任何可兑换 Key。
- Compare 工具的数值字段没有公开来源时统一为 Not published / 待确认，不用 0 或猜测值填充。

> OK, I found a solution to the problem.
>
> The issue was that I rebound the helicopter collective control to the Spacebar, but doing that overwrote the parachute keybind, and there’s no way to rebind Deploy Parachute in the settings.
>
> So I had to fix it manually.
>
> Go to this file:
>
> C:\Users\[your username]\AppData\Local\Wardogs\Saved\Config\WindowsClient\GameUserSettings.ini
>
> Find the line containing "DeployParachute" and delete it.
>
> Basically, when I bound the Spacebar to the helicopter collective, the game replaced the Deploy Parachute bind with no key at all.
>
> Deleting that line makes the game restore the default parachute keybind.

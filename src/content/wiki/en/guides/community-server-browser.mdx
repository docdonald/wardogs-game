## How do you open the WARDOGS Community Server Browser?

From the Play screen, press **DEPLOY** to open the current server selection flow. Update 0.1.2 now presents **Official**, **Community**, **Infantry Mode**, and **Low-Level** choices before you enter a server list. Choose Community for a player-hosted server, Infantry Mode for the advertised infantry modifier, or Low-Level when you want a server that highlights lower-level play.

Community servers keep text search and filtering for named hosts and populations. Update 0.1.2 also adds Advanced Filters back to the Official server list, so the old Patch 0.11 description of a filter-free Official view is no longer current.

## What is the exact Server ID join path?

Use this path from the game’s Play screen:

**DEPLOY → Community → server list → JOIN BY ID (bottom-left) → enter the Server ID → LOOKUP**

The current DEPLOY category selection comes first; the **JOIN BY ID** control remains in the Community list. It opens a small Find Server box with an **ENTER SERVER ID** field. Type the six digits without the dash. For example, enter `700118` when the browser displays `700-118`, then press **LOOKUP**. A successful lookup moves you into the connection flow for that server.

The button location and six-digit input flow are also described by [All Things How’s Server ID guide](https://allthings.how/wardogs-how-to-join-a-server-by-id-from-the-server-browser/) and [Shacknews’ squad guide](https://www.shacknews.com/article/150731/invite-friends-create-squad-wardogs).

## Where do you find a server’s ID?

Select a server row in the browser. The details panel shows the map, region, host, and the server’s ID near the bottom of the panel. Share those six digits with your squad while the match is active, then have the other players enter them through **JOIN BY ID**.

Patch 0.11 makes Community Server IDs persist between matches and restarts, and each server has its own unique ID. You can therefore use the ID as the quickest way to regroup instead of asking several players to type a long server name into the search field.

## How do friends join the same match?

The fastest sequence is for one player to enter the server first, read the Server ID from the details panel, and send it to the group. Everyone else can use **JOIN BY ID** and press **LOOKUP**. Steam invitations are another option after a player has joined: open the Steam friends list, right-click a friend, and choose **Invite To Game**.

If a lookup fails, refresh the browser and request the current ID again. Check every digit and make sure the server is still available. A closed session, a restarted hosting process, or one mistyped digit can leave you on the browser with no matching result.

## Which Community filters should you use?

Start with the text search when you know the host or server name. Then narrow the list by the region and population that fit your squad. The quick bar can show or hide empty and full servers, which makes it easier to find an active lobby without repeatedly opening a detailed filter panel.

Use the server details before joining. Check the map, region, current population, and any visible rules or naming cues. A server with the right name but the wrong region can create unnecessary ping, while a server that is still seeding may not have enough players for a complete match yet.

## Does a Community Server give extra cash?

Patch 0.11 offered Community Servers a **5% End of Match cash bonus for one week**. That time-limited promotion is now historical; it was applied to the match-end payout rather than every Control Zone tick or individual action. See the [WARDOGS cash guide](/mechanics/how-to-make-money) for current cash routes and spending advice.

## What else changed in Patch 0.11?

Patch 0.11 improved Community filtering, added text search, added Show Empty/Full controls, and pointed the Host button to the correct location. Update 0.1.2 adds the DEPLOY categories, restores Advanced Filters for Official servers, keeps long names visible on hover, shows queue position after Join, and supports a gamepad on the DEPLOY screen. The [full Patch 0.11 notes](/updates/patch-0-11) and [Update 0.1.2 entry](/updates/patch-0-1-2) cover the dated changes.

Community-server favouriting, tiered priority queues, a message-of-the-day prompt, improved warmup activities, AFK seeding controls, and team-switching controls are listed as upcoming work. They are separate from the browser and Server ID tools available in the current patch.

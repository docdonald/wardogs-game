## What is new in WARDOGS Patch 0.11?

Patch 0.11 is the server-browser update released after the September 14 maintenance window. It separates Community and Official browsing, improves the way Community servers are found, and adds a direct Server ID route for regrouping with friends. It also starts a one-week **5% End of Match cash bonus** for Community Servers.

The update is aimed at making player-hosted matches easier to discover without changing the three-team Control Zone match structure. Use the [Community Server Browser guide](/guides/community-server-browser) for the button-by-button route and the current search workflow.

## How did the server browser change?

The front end now has separate **Community** and **Official** browsers. Official-server filtering is removed because the current Official browser does not need modified-mode filters. Community filtering is more reliable and now includes text search, so players can search by a server name instead of scanning every row.

The quick bar adds **Show Empty/Full** controls. The update also sends the **Host** button to the correct location, sorts server names alphabetically regardless of special characters and numbers, and prevents server names from using more than one consecutive space.

## How do Community Server IDs work?

Community Server IDs now persist between matches and restarts, with each server receiving its own unique ID. To join one, open **DEPLOY**, enter the Server Browser, click **JOIN BY ID** in the bottom-left, type the six digits, and select **LOOKUP**. A displayed ID such as `700-118` is entered as `700118`.

The ID route is useful when a squad is already in a match. Select the server row to see its details and read the ID from the panel, then send the digits to the rest of the group. Steam invitations remain available after a player joins a server.

## How does the 5% cash bonus work?

For the next week after Patch 0.11, Community Servers provide a **5% End of Match cash bonus**. The bonus belongs to the match-end payout. It is not a 5% increase on every Control Zone tick, revive, transport run, or other mid-match action.

Finish the match when you want the bonus to be included in the final payout, then compare the end-of-match cash result with your normal match earnings. The [cash guide](/mechanics/how-to-make-money) covers safe routes, Hot Zone income, transport, logistics, and the cost of each life.

## What other fixes shipped with the patch?

The patch fixes various cash exploits, addresses more GPU crash paths, and increases server capacity in Asia. The economy-abuse policy in the same announcement says repeated cash exploit abuse can lead to a timed ban and a cash and XP reset, while content that teaches economy exploits can lead to a permanent ban. XP-farming servers can also trigger permanent account penalties.

Those enforcement notes matter when choosing a Community Server. Use ordinary player-hosted matches and avoid servers or videos that advertise ways to inflate cash or XP outside the normal match loop.

## Which browser features are still coming?

The announcement lists Community server favouriting, tiered priority queues, a message-of-the-day prompt, improved warmup activities, AFK kicking controls during seeding, and team-switching controls as upcoming features. They are planned browser improvements, not extra buttons required for the current Server ID flow.
